CUMPLIMIENTO // COLOMBIA LEY 1581 DE 2012

Gobernanza Habeas Data Nativa y Baja en Un Clic

Cada comunicación incluye cabeceras técnicas List-Unsubscribe: <mailto:...> bajo el estándar RFC 8058 y cláusulas de contacto corporativo B2B. Si un prospecto responde negativamente, el DispatchAgent lo clasifica como OPT_OUT y bloquea futuros envíos de forma permanente.

List-Unsubscribe-Post: List-Unsubscribe=One-Click
ReplyIntent.OPT_OUT -> is_blacklisted = True
AuditLog: Actor=dispatch_agent Action=OPT_OUT
